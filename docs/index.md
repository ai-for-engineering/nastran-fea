**ai-for-engineering** is an umbrella project exploring AI applications across
engineering disciplines. The first exploration, documented here: AI-driven
finite element analysis in native Nastran bulk-data format, using
open-source tools only — no commercial solvers, no proprietary formats.

The code lives at
[github.com/ai-for-engineering/nastran-fea](https://github.com/ai-for-engineering/nastran-fea).
